Counter with Undo/Redo

This is a simple counter application with Undo and Redo functionality. The counter allows incrementing and decrementing by various values, and each action is logged in a history list.

Features

Increment or decrement the counter by 1, 10, or 100.

Undo the last operation.

Redo a previously undone operation.

View action history in the format: ACTION (BEFORE -> AFTER).

Technologies Used

HTML

CSS

JavaScript

How to Use

Click on + or - buttons to change the counter value.

Click Undo to revert the last action.

Click Redo to reapply an undone action.

The history section logs each action performed.

File Structure

index.html - The main structure of the app.

style.css - The styling for the app.

script.js - The logic for counter, undo/redo, and history tracking.
